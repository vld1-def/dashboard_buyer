Facebook tokens

System user tokens: where the dashboard reads stats from, and what it pauses campaigns with.

The token is checked against Facebook the moment you add it — you see its permissions, expiry and how many ad accounts it can reach. Nobody can read it back afterwards, you included: the database grants no access to that column, and only the server function retrieves it. Where to get a token: see FB_TOKENS.sql.

Ad accounts from Facebook

What Marketing API says about every ad account those tokens can reach: state, today's spend, what is live inside, which card pays. Pulled automatically every hour.

Hourly is a deliberate choice, not a limitation: Facebook counts even refused requests against the rate limit, and hitting it means not even the account state comes through — the one thing this is for. Numbers read live/total, so 3/40 means three of forty campaigns are running. Spend is today in the ad account's own time zone, the way Facebook counts it. The card shows the type and last four digits — Marketing API does not expose the BIN anywhere, so there is nothing else to show. Setup: FB_SYNC.sql, then FB_SYNC_CRON.sql.
