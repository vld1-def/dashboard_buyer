PWA · campaign parsing

Where geo and KTID sit inside the campaign name. The same pattern is used on both sides of the import — Facebook and Keitaro — because rows are merged by date|account|geo|ktid. Change it here and both sides move together. The account and the creative are taken from the report columns, not from the name, so they are not in the pattern.

How to write the pattern

  • {geo} — geo, two letters
  • {ktid} — KTID, the funnel id
  • * — anything: one chunk or several
  • Melbet — literal text: must match exactly

A tail the pattern does not describe is ignored, so *_{geo}_{ktid} is enough for Melbet_EG_10864-9lm5_19/09_001 — the date and the number at the end need no mention. How many characters {…} takes is decided by the character right after it.

If a name does not match, geo becomes ?? and KTID becomes 0 — the row is still written. After the import you will be told how many names did not match. Check here first.

APP · campaign parsing

Every provider builds the campaign name its own way, so each gets its own profile. To tell whose layout it is, in KTID Mappings put the provider in square brackets in the funnel name — e.g. Mostbet [AppCloud]. An app from such a funnel is parsed with the profile AppCloud; with no brackets, the default profile is used.

How to write the pattern

  • {app} — app name (also the KTID)
  • {acc} — account id
  • {cid} — creative · {cid-} if it uses "-" instead of "_"
  • {geo} — geo
  • {app=SNATCH} — force this value when the name has none
  • * — anything: one chunk or several
  • sub4 — literal text: must match exactly

Naming can be anything — tokens split by "_" or "&sub2=…&sub3=…". Write the pattern the way the name looks, replacing the parts you need with {…}, and the rest with *. How many characters {…}, takes is decided by the character right after it: in sub4={cid} the creative may contain "_", but in {cid}_{geo} — it may not. A tail the pattern does not describe is ignored. Anything missing from the pattern is taken from the report columns: {cid} from Ad name, {geo} from Country.
