# Джерела збірки

`index.html` у корені — **згенерований файл**. Руками його не правлять:
наступна збірка перезапише правку, і слідів не лишиться.

Правлять те, що тут, і запускають:

```
python3 build/build.py
```

Збірка бере `index-legacy.html` і накладає на нього цю теку:
новий `<head>`, шар дизайну, каркас сторінки і точкові патчі JS.

## Чому межі шукаються за вмістом, а не за номерами рядків

`build.py` знаходить місце вставки за фрагментом тексту, а кожен патч
робить через `sub()`, який вимагає **рівно один** збіг. Тому правка в
`index-legacy.html`, яка зачепила рядок, на який спирається патч,
ламає збірку **вголос**, з назвою патча — замість того, щоб тихо
нічого не замінити й віддати сторінку, де бракує половини поведінки.

Збірка впала — це не поломка, це спрацював запобіжник. Дивіться, який
патч названо, і правте його анкер.

## Що де лежить

| файл | що це |
|---|---|
| `build.py` | сама збірка: анкери, патчі, штамп дати |
| `design.css` | весь шар дизайну |
| `head.html`, `shell.html` | `<head>` і каркас сторінки |
| `widgets.js` | дашборд: KPI, таблиці, експорт у CSV/XLSX |
| `trend.js` | графіки: спенд і net profit, підсумки по точках |
| `close.js`, `payslip.*` | закриття місяця, ROI, виплати |
| `cabinets.*`, `cabdrill.js`, `fbtok.js` | кабінети, токени, деталізація |
| `fbrep.js` | експорт звіту з кабінета у формат, який читає `Form.html` |
| `fbcom.js`, `fbpages.js` | коментарі й сторінки |
| `rules.*` | автоправила (пара до Edge Function `fb-rules`) |
| `domains.*` | домени (пара до `check-domains`) |
| `uniq.*`, `cover.py` | унікалізатор відео й обкладинки |
| `files.*`, `team.*`, `events.js`, `tg.js` | файли, команда, події, Telegram |
| `geocost.js`, `geomodal.js`, `fresh.js`, `toast.js` | гео, свіжість даних, повідомлення |
| `i18n.py` | переклад інтерфейсу на етапі збірки |

## Що НЕ збирається

`Form.html` (імпорт звітів), `index-legacy.html` і `supabase/functions/*`
правлять напряму — вони не проходять через `build.py`.

## Перевірка, що нічого не загубилось

Збірка має давати той самий `index.html`, що вже в репозиторії, — з
точністю до двох рядків зі штампом дати:

```
cp index.html /tmp/ref.html
python3 build/build.py
diff <(grep -v 'name="build"' /tmp/ref.html) <(grep -v 'name="build"' index.html)
```

Порожній вивід — джерела повні.
